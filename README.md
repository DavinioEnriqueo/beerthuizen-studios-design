# Beerthuizen Studios — designopdracht voor Hermes

Open de huidige website hier: https://app.beerthuizenstudios.nl/login

## Opdracht
Maak uitsluitend een professioneel visueel redesign van de website en portalen. Houd de stijl premium, rustig, modern en volledig zwart-wit. Verbeter typografie, leesbaarheid, spacing, hiërarchie, animaties en responsive gedrag op telefoon, tablet en laptop.

## Belangrijk
- Wijzig geen authenticatie, API-routes, database, gebruikersrollen, boekingslogica, betalingen, toegangscodes, deurkoppeling, tabletlogica of beveiliging.
- Behoud alle bestaande functies en Nederlandse inhoud.
- Gebruik natuurlijke studiofotografie en het bestaande Beerthuizen Studios-logo.
- Lever de designwijzigingen op een aparte branch of als pull request aan.
- Deze repository is uitsluitend voor de designuitwerking; publiceer niets rechtstreeks naar de live website.

## Functionele pagina’s die visueel moeten blijven kloppen
- openbare pakkettenpagina en klantlogin
- registratie en voorwaarden
- klantdashboard en boeken
- beheerderdashboard
- schoonmaakweergave
- studio-tablet
- artikelen, privacybeleid en algemene voorwaarden

De eigenaar voegt de aangepaste designbestanden later samen met het afgeschermde productiesysteem.
